Phase F 已经完成了可复现的工程基础：动作事务接口、求解器状态分类、显式延迟顶点、能力下界、滚动共同控制序列 QP 和诚实的 Gate 停止。但 G5 的失败不能直接解释为 CDSR-MPC 或方向1失败。其主要原因是：

1. 用跨事故、跨能力变化、跨估计器瞬态的全局残差，构造了每个控制周期都可独立发生的终端加性扰动；
2. 一步频率、ACE 和联络线残差半径已经大于终端限制，零状态也无法对该集合正不变；
3. 在 SG 备用不足的场景中，要求 SG-only 无限时域接管持续功率缺额，与研究场景本身矛盾；
4. 只测试了两个固定 backup 反馈，不能证明不存在控制不变终端集合；
5. 当前有限时域鲁棒约束仍未完整覆盖 SG 机械功率、实际延迟 BESS 功率和能量；
6. F4 只有开发点上的单步动作测试，尚未形成闭环比较结果。

本轮不更换核心方法名称，也不添加 AI、RL 或模式分类。继续采用 CDSR-MPC，但重构：
