## 当前包针对的历史结果

本启动包基于：

```text
DIRECTION5_VOI_ACCR_MPC_SINGLE_REVIEW_PACKAGE.zip
```

的独立审查。历史包得到的负结论对**冻结的启发式VOI门、固定二步探测和有限MPC设置**有效，但不能外推为：

- 任何安全主动能力辨识都没有价值；
- 价值信息边界为空；
- 方向5科学问题不成立。

## 本轮唯一论文目标

> **建立黑箱IBR能力信息的控制价值边界，证明何时任何安全探测都不值得、何时存在净正价值的安全探测，并实现一个只在正价值区域探测、其余状态严格退化为合同MPC的选择性VOI-ACCR-MPC。**

本轮不再追求“所有场景全局平均显著提升”。论文的核心结果是：

1. 一个可重算的 value-of-information boundary；
2. 一个 no-probe theorem；
3. 一个 safe positive-probe sufficient condition；
4. 一个选择性控制器；
5. 正价值区域的净收益与无价值区域的安全放弃。

- 只有三个宽里程碑，不在中间询问用户；
- 在形成“证据里程碑”前禁止Git提交；
- Codex可以在development范围内自动采样和优化，但不得修改物理范围、validation/final数据、统计规则和成功标准；
- 最终必须得到一篇边界/方法论文，或者一篇具有严格边界证据的负结果论文；
- 禁止通过删除不利结果、修改final或扩大事故制造正区域。
