# B0 formulation lock

## Registered decision problem

The boundary calculation uses the same two-area dynamics and the same fixed
finite-horizon policy family for every comparison. The augmented prediction state is

\[
z_k=(\omega_{1:2},p_{tie},p_{v,1:2},p_{m,1:2},p^{POI}_{b,1:2},
      h_{1:2},E_{1:2}).
\]

The ordinary controller observes the grid state, actual BESS POI power, measured SoC,
the issued-command delay pipeline, and the causal persistent-load estimate. Hidden
power, ramp, and delay values enter only through the retained outer candidate set.
True capability is used only by the evaluation-side hypothesis rollout.

At a boundary point \(\xi\), the controller class is a common issued-command sequence
over the supplied candidate set. Every sequence obeys SG valve/mechanical/GRC limits,
BESS physical command rating, candidate-specific delivered-power/ramp/delay limits,
measured-SoC energy margin, and grid frequency/tie constraints. The fixed objective is

\[
\ell=\Delta t\left[
\sum_i(f_i/0.20\;\mathrm{Hz})^2+
\sum_i(ACE_i/0.08\;\mathrm{pu})^2+
(p_{tie}/0.04\;\mathrm{pu})^2+
\sum_i(\Delta p_{SG,i}/0.03\;\mathrm{pu})^2+
\sum_i(\Delta u_{B,i}/0.03\;\mathrm{pu})^2\right].
\]

Thus frequency, ACE, and tie-line responsibility are all nonzero. The physical horizon
is fixed in seconds; 2 s and 4 s control periods differ only in discretization and in
the number of samples used to realize the same physical probe duration.

## Values

For the retained set \(\Theta\),

\[
J^R=\min_{\pi\in\Pi_N}\max_{\theta\in\Theta,w\in\mathcal W}L(\pi,\theta,w),
\qquad
J^{PI}=\max_{\theta\in\Theta}\min_{\pi\in\Pi_N}
\max_{w\in\mathcal W}L(\pi,\theta,w),
\]

and \(V^{PI}=J^R-J^{PI}\). This is the registered-formulation value; no
different-horizon or different-weight Oracle is used.

A probe is an SG--IBR allocation perturbation around the current robust contract-MPC
sequence. At every sample its BESS component is \(q_k\), its SG component is
\(-q_k\), and its discrete physical-time integral is zero. All candidate rollouts must
remain safe, including the non-delivery/saturation branches.

The measured statistic is a registered matched-filter projection of the complete
actual POI-power trace. Bounded noise and residual mismatch give one closed interval
\(Y_\theta(q)\) per hypothesis. Sorting all interval endpoints enumerates every
nonempty posterior exactly for this statistic; no Monte Carlo observation is used in
the inner problem. For every possible posterior \(P\), the remaining-horizon robust
MPC is re-solved from the measured post-probe state and measured POI power. The full
prefix cost plus worst posterior recourse is \(J^q\), and

\[
V(q)=J^R-J^q.
\]

The corresponding upper value replaces each posterior by the true singleton after
the identical probe prefix. It therefore credits the probe with perfect post-probe
information while retaining its complete state excursion and resource cost.

For dense boundary screening, the same upper value has a second, cheaper conservative
bound. After eliminating the linear prediction states, each singleton objective has
the quadratic form

\[
J_\theta(u)=u^T H_\theta u+b_\theta^T u+c_\theta,
\qquad H_\theta\succ0,
\]

where \(H_\theta\) includes the normalized frequency, ACE, tie, SG-move, and
BESS-move terms. Partitioning commands into the fixed probe prefix \(u_a\) and free
recourse tail \(u_b\), the minimum quadratic penalty for fixing \(u_a\) away from the
singleton optimum is bounded below by

\[
(u_a-u^*_{\theta,a})^T
\left(H_{aa}-H_{ab}H_{bb}^{-1}H_{ba}\right)
(u_a-u^*_{\theta,a}).
\]

The Schur complement is evaluated separately for every capability vertex and physical
probe duration. Constraints can only increase this penalty. The resulting value is a
rigorous *upper* bound on probe value without re-solving the recourse QP. A positive
quadratic bound is inconclusive and is sent to the full perfect-posterior calculation;
a nonpositive bound proves no-probe for that registered point.

## No-probe result

For every safe probe \(q\), the true singleton contains at least as much information
as any causal posterior generated by that probe. Consequently

\[
J^q \ge J^{q,PI},\qquad V(q)\le U(q):=J^R-J^{q,PI}.
\]

Hence, if \(\max_{q\in\mathcal Q_{safe}}U(q)\le0\), no causal posterior policy in the
registered class can improve on contract MPC. Two stronger special cases are also
used: (i) \(V^{PI}\le0\), or (ii) the registered safe-probe set is empty. A screened
development run cannot claim this theorem unless all safe probes were evaluated or
one of the two special cases holds.

The selective controller is therefore defined without a load label:

\[
q^*=\arg\max_{q\in\mathcal Q_{safe}} V(q),\qquad
\pi^{sel}=\begin{cases}
\pi^{q^*},&V(q^*)>0,\\
\pi^R,&V(q^*)\le0.
\end{cases}
\]

The abstention branch invokes the same contract-MPC object, state, solver settings,
and first action. Numerical equivalence is tested in the nonlinear experiments rather
than inferred from similar configuration values.

## Scope of the finite candidate result

The B1 engine exactly covers the registered vertex set and bounded scalar observation
tubes. Continuous in-cell capabilities are handled later by an outer residual and an
explicit conservative deliverability floor; native Plant B is not used to generate the
boundary. A theorem statement will be limited to that declared uncertainty set. Any
unclassified volume, solver failure, or outer-model violation remains unclassified and
cannot be counted as a zero-value point.
